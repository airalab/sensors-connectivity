# Security policy

## Reporting a vulnerability

Please do not report security problems in public issues.

Use GitHub private vulnerability reporting: open the
[Security tab](https://github.com/airalab/sensors-connectivity/security) of this
repository and choose **Report a vulnerability**. Only the maintainers see the
report.

Include what is affected (version or commit), how to reproduce it and the impact
you expect. We will acknowledge the report and keep you updated until it is
fixed.

## Supported versions

Only the latest release published on
[PyPI](https://pypi.org/project/sensors-connectivity/) and the `master` branch
receive security fixes.
